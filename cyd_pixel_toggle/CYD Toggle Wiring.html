Pixel Toggle Wiring

Your CYD (the “Cheap Yellow Display”) is a one-board computer: the ESP32, the screen and the touch chip are already wired together. So there is no breadboard to build. This sheet shows the three things you do set up: the USB cable, the Wi-Fi, and the bulb. Pick a step to see only that part.

The alternate build: an ESP32 dev board on your two half-size breadboards, wired to a separate 2.8 in touch-screen module. It uses the same ESP32 pins the CYD has inside, so the same sketch runs with no code changes. Columns run 30 on the left to 1 on the right, as printed on your boards. Pick a step to see only its wires.

First power-up and Serial Monitor

The Serial Monitor is a text window connected to the board over USB. It shows what the sketch prints, which is the fastest way to see what the board is doing. SETUP.md has the full test checklist.

Open it

  1. Close any other monitor on that port first, including the Arduino IDE’s Serial Monitor: only one program can use a port at a time.
  2. Find the port name.
    arduino-cli board list
  3. Open the monitor. Swap XXXX for what the list showed.
    arduino-cli monitor -p /dev/cu.usbserial-XXXX --config 115200
  4. Press Ctrl+C to quit.

In the Arduino IDE: Tools › Serial Monitor (⌘⇧M), 115200 baud.

Opening a monitor restarts the board. That is normal. Quit the monitor before you upload, or the upload fails with “Resource busy”. Upload at 115200 (Tools › Upload Speed).

What the board prints

[draw] picture buffer: … bytes in … strip(s)   ← at start
[mem] free heap …, biggest free block …        ← at start
[touch] using saved calibration                ← or “calibration done and saved”
[lifx 3.2s] Wi-Fi connected, this board's address is …
[lifx 5.0s] using bulb … at 192.168.…
[sync] bulb is ON -> toggle follows            ← toggle matches the bulb
[lifx …] tap: bulb should be OFF               ← when you tap
[lifx …] bulb confirmed: it is OFF
[fps] … fps while animating | draw … us …      ← every 2 s while it moves

On the screen, first time

  1. A “PIXEL TOGGLE” splash for about 1.6 seconds.
  2. First run only: “Touch calibration”. Tap the centre of each mark as it appears. The result is saved in the board and not asked for again.
  3. The toggle appears in dark mode, then flips to match the bulb once the bulb answers.
  4. Tap the toggle. It slides, and the bulb fades on or off over about 0.3 seconds.

Redo the calibration later: press RESETthe EN button, then hold BOOT (or keep a finger on the glass) while the splash shows. Do not hold BOOT while pressing RESETEN: that puts the chip into upload mode.
